Utility to apply the stamp generated by `PDF::Watermark::PDF` in `imgsrv` onto a born digital PDF.

Uses https://pdfbox.apache.org/.

## Releases

JAR files are published automatically via GitHub Actions when a version tag is pushed. The consumer script `stamp_pdf.pl` lives in https://github.com/hathitrust/babel and downloads the JAR from the latest release at stage time.

To publish a new release:

```sh
git tag v1.2
git push origin v1.2
```

The workflow will build and publish `stamper.jar` as a release asset automatically.

## Building

```sh
mvn clean package
```
